Radar

Radar search and track façade used by the mission computer. The mock models a multimode set: range-while-search, single-target track, and air-to-ground mapping.

Modes

  1. RWS — range while search
  2. STT — single target track
  3. TWS — track while scan
  4. SAR — synthetic aperture (air-to-ground)

Public types

RadarSuite and radar.h.

Cueing

if (radar.mode() == Mode::STT) {
hud.cue(radar.primary().bearing, radar.primary().range_nm);
}
