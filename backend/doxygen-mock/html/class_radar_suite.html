RadarSuite

Multimode radar search and track façade.

Synopsis

class RadarSuite {
public:
enum class Mode { RWS, STT, TWS, SAR };
struct Track { float bearing; float range_nm; float closing_kts; };
Mode mode() const;
Track primary() const;
void set_mode(Mode mode);
};

Member functions

mode / set_mode

Read or request a radar mode. Mode changes take effect on the next 50 ms frame.

primary

Highest-priority track used by HUD cueing. Empty when the suite is in SAR mapping.
